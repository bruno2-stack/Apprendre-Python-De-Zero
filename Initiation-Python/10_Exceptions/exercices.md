# Mini-Projet : Calculatrice robuste

Créer un programme nommé :

```text id="r7s8t9"
calculatrice_securisee.py
```

Fonctionnalités :

* Demander deux nombres
* Demander une opération (+, -, *, /)
* Gérer :

  * division par zéro
  * saisie invalide
* Afficher un message propre en cas d’erreur
