# Mini-Projet : Carte d'Identité

Créer un programme nommé :

```text
carte_identite.py
```

Le programme doit afficher :

```text
********************************
      CARTE D'IDENTITÉ
********************************

Nom : ...
Prénom : ...
Age : ...
Ville : ...
Profession : ...

Merci d'utiliser Python !
```

Toutes les informations doivent être stockées dans des variables avant l'affichage.
