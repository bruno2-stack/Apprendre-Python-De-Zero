# 1. Qu'est-ce que Python ?

Python est un langage de programmation créé en 1991 par Guido van Rossum.

Il est :

* Simple à apprendre
* Facile à lire
* Gratuit et Open Source
* Multi-plateforme (Windows, Linux, macOS)
* Très utilisé dans le monde professionnel

Python est aujourd'hui l'un des langages les plus populaires au monde.

---

# 2. Pourquoi apprendre Python ?

Python est apprécié pour sa syntaxe claire et sa simplicité.

### Exemple

```python
print("Bonjour le monde")
```

Comparé à d'autres langages, Python nécessite moins de code pour accomplir une tâche.

# 4. Installation de Python

## Sous Windows

1. Télécharger Python depuis :

https://www.python.org/downloads/

2. Lancer l'installation.

3. Cocher :

```text
Add Python to PATH
```

4. Cliquer sur :

```text
Install Now
```

---

# 5. Vérification de l'installation

Ouvrez l'invite de commande et tapez :

```bash
python --version
```

ou

```bash
py --version
```

Résultat attendu :

```text
Python 3.x.x
```

# 7. Premier programme Python

Créer un fichier :

```text
bonjour.py
```

Écrire :

```python
print("Bonjour le monde")
```

Enregistrer puis exécuter :

```bash
python bonjour.py
```

Résultat :

```text
Bonjour le monde
```

---

# 8. Comprendre la fonction print()

La fonction print() permet d'afficher du texte à l'écran.

Exemple :

```python
print("Bienvenue en Python")
```

Résultat :

```text
Bienvenue en Python
```

---

# 9. Utilisation de l'interpréteur Python

Ouvrir le terminal :

```bash
python
```

Vous obtenez :

```text
>>>
```

Vous pouvez exécuter directement des instructions :

```python
print("Bonjour")
```

Résultat :

```text
Bonjour
```

Quitter :

```python
exit()
```

---

# 10. Les commentaires

Les commentaires permettent d'ajouter des explications dans le code.

Ils ne sont pas exécutés.

Exemple :

```python
# Ceci est un commentaire

print("Bonjour")
```

---

# 11. Les erreurs de programmation

Les erreurs font partie de l'apprentissage.

Exemple :

```python
prit("Bonjour")
```

Résultat :

```text
NameError
```

L'erreur indique que Python ne connaît pas la fonction "prit".

Il faut écrire :

```python
print("Bonjour")
```
