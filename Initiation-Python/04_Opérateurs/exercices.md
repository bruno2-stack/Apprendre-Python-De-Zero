# Mini-Projet : Calculatrice simple

Créer un programme nommé :

```text id="n5o6p7"
calculatrice.py
```

Fonctionnalités :

* Demander deux nombres
* Afficher un menu :

  * +
  * *
  * *
  * /
* Afficher le résultat selon l'opération choisie

Exemple :

```text id="q8r9s0"
Choisissez une opération (+, -, *, /) : +
Nombre 1 : 10
Nombre 2 : 5

Résultat = 15
```
