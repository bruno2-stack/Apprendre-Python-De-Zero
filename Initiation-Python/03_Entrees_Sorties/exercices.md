# Exercices

## Exercice 1

Demander à l'utilisateur :

```text
Nom
Prénom
Ville
```

Puis afficher les informations.

---

## Exercice 2

Demander deux nombres puis afficher leur somme.

Exemple :

```text
Nombre 1 : 5
Nombre 2 : 10

Somme = 15
```

---

## Exercice 3

Demander l'âge d'un utilisateur puis afficher :

```text
Dans 5 ans vous aurez X ans.
```

---

## Exercice 4

Demander :

```text
Longueur
Largeur
```

Calculer puis afficher la surface d'un rectangle.

Formule :

```text
Surface = Longueur × Largeur
```

---

# Mini-Projet : Fiche Étudiant

Créer un programme nommé :

```text
fiche_etudiant.py
```

Le programme doit demander :

```text
Nom
Prénom
Age
Classe
Ville
```

Puis afficher :

```text
=========================
      FICHE ÉTUDIANT
=========================

Nom :
Prénom :
Age :
Classe :
Ville :

Merci pour votre inscription.
```

Toutes les informations doivent être saisies par l'utilisateur à l'aide de `input()`.
