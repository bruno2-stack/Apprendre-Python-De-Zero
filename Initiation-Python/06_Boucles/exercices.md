# Mini-Projet : Jeu de devinette

Créer un programme nommé :

```text id="z7a8b9"
jeu_devinette.py
```

Fonctionnement :

* Un nombre secret est choisi (ex: 7)
* L'utilisateur doit deviner
* Tant que la réponse est fausse, le programme continue
* Si correct → message de victoire

Exemple :

```text id="c1d2e3"
Devinez le nombre : 3
Faux, réessayez
Devinez le nombre : 7
Bravo !
```
