# 📖 Présentation

Ce dépôt a été conçu pour accompagner les débutants dans l'apprentissage de la programmation Python.

La formation couvre progressivement les concepts fondamentaux du langage, depuis l'installation de Python jusqu'à la création de programmes modulaires organisés en plusieurs fichiers.

Chaque chapitre contient :

* Une partie théorique
* Des exemples pratiques
* Des exercices
* Des mini-projets

---

# 🎯 Objectifs pédagogiques

À la fin de cette formation, l'apprenant sera capable de :

* Comprendre la syntaxe Python
* Manipuler les variables et les types de données
* Utiliser les structures conditionnelles
* Créer des boucles
* Développer des fonctions
* Manipuler les listes, tuples et dictionnaires
* Gérer les fichiers
* Utiliser les modules Python
* Créer ses propres modules
* Structurer un projet Python

# 📚 Plan de formation

## Chapitre 1 : Introduction à Python

* Présentation de Python
* Installation de Python
* Installation de VS Code
* Premier programme

## Chapitre 2 : Variables et Types de données

* Variables
* Entiers
* Réels
* Chaînes de caractères
* Booléens

## Chapitre 3 : Entrées et Sorties

* print()
* input()
* Formatage des chaînes

## Chapitre 4 : Opérateurs

* Arithmétiques
* Comparaison
* Logiques

## Chapitre 5 : Structures Conditionnelles

* if
* if...else
* if...elif...else

## Chapitre 6 : Boucles

* while
* for
* break
* continue

## Chapitre 7 : Fonctions

* Définition
* Paramètres
* Valeurs de retour
* Portée des variables

## Chapitre 8 : Collections

* Listes
* Tuples
* Ensembles
* Dictionnaires

## Chapitre 9 : Manipulation des Fichiers

* Lecture
* Écriture
* Ajout de contenu

## Chapitre 10 : Gestion des Exceptions

* try
* except
* finally

## Chapitre 11 : Modules Python

* Importation
* Création de modules
* Réutilisation du code

## Chapitre 12 : Modularité

* Organisation des projets
* Packages
* Bonnes pratiques
